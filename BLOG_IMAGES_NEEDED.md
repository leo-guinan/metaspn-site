## Design Guidelines

### Color Palette
- **Primary Background:** #0D0D0D (very dark gray/black)
- **Accent Color:** #00D4FF (neon blue)
- **Text Color:** #FFFFFF (white)
- **Secondary Accent:** #FF3366 (accent magenta)

### Typography
- **Headings:** Montserrat Bold
- **Body Text:** Inter Regular
- **Consistent with main site branding**

### Style Requirements
- Dark theme throughout
- Neon blue highlights and accents
- Clean, modern design
- Professional yet innovative feel
- Consistent with MetaSPN brand identity
- High contrast for readability
- Optimized for both desktop and mobile viewing

## File Naming Convention
- Featured images: `[post-slug]-featured.jpg`
- Open Graph images: `[post-slug]-og.jpg`
- Author images: `leo-guinan.jpg`
- Blog index: `blog-og.jpg`

## Technical Requirements
- **Format:** JPG (for photos) or PNG (for graphics with transparency)
- **Quality:** High resolution, optimized for web
- **File Size:** Under 500KB per image for web performance
- **Alt Text:** Descriptive alt text for accessibility
- **Responsive:** Images should look good at various sizes
